# JOURNAL — *Your journey becomes its own grid*

여행 사진과 촬영 데이터를 모듈형 그리드로 변환하는 제스처 기반 인터랙티브 비주얼 저널.
Swiss International Typographic Style · 흑/백/중성 회색 UI · 사진에서 추출한 강조색 1가지.

여행의 **시간·이동·장소·기억의 강도**가 레이아웃 규칙이 되어, 사진을 정리하는 과정 자체가
하나의 퍼포먼스가 되고, 완성물은 개인 여행 기록을 반영한 고유한 포스터/디지털 저널이 됩니다.

## 원칙
- **의존성 0** (코어). 빌드 도구·프레임워크 없음. `index.html`을 열면 바로 동작.
- **서버 업로드 없음.** 모든 사진은 브라우저 안에서만 처리 (로컬 전용).
- **회원가입 없음.**
- **GitHub Pages 즉시 배포 가능** (정적 파일뿐).
- 손동작(웹캠)은 옵트인 옵션이며, 이 기능만 최초 1회 CDN에서 MediaPipe를 불러옵니다.
  웹캠 없이도 전체 편집이 정상 동작합니다.

## 실행
정적 파일이라 어떤 방식으로든 열 수 있습니다.

```bash
# 아무 정적 서버나 사용 (예)
npx serve .
# 또는 Python
python -m http.server 8000
```

브라우저에서 열기만 해도 되지만, 일부 브라우저는 `file://`에서 웹캠·일부 기능을
제한하므로 로컬 서버 사용을 권장합니다.

## GitHub Pages 배포
1. 이 폴더의 내용을 저장소 루트(또는 `/docs`)에 넣습니다.
2. Settings → Pages → Source를 해당 브랜치/폴더로 지정합니다.
3. 추가 빌드 단계 없이 그대로 배포됩니다.

## 사용법
1. **사진 불러오기** — 왼쪽 인덱스의 “파일 선택” 또는 드래그&드롭 (여러 장 동시). JPEG는
   촬영 시간·GPS(EXIF)를 자동으로 읽습니다.
2. **배치** — 인덱스 썸네일을 중앙 캔버스로 끌어다 놓으면 가장 가까운 그리드 셀에 스냅됩니다.
3. **편집** — 요소를 선택하면 오른쪽 인스펙터에서 크기(그리드 칸)·확대·크롭/위치·캡션·교체·
   레이어·삭제를 조절. 모서리 핸들로 리사이즈, 크롭 모드에서 드래그로 이동·휠로 확대.
4. **타이포그래피** — “＋ 텍스트” 또는 인스펙터의 제목/장소/날짜/메모를 그리드에 추가.
   대형 타이포는 Apple Garamond(로컬 설치 시), 본문은 Helvetica 산세리프.
5. **Memory Grid** — 촬영 데이터로 초기 레이아웃 자동 제안 (시간·장소 묶기, 긴 간격은 넓은 여백,
   밤 사진 차별화, 강조색 추출).
6. **명령 입력창** — 예: “촬영 시간순으로 정리”, “밤 사진을 오른쪽에”, “제목을 왼쪽 위에 크게”.
7. **손동작(옵션)** — 손바닥 이동=밀기, 오므리기=선택, 양손 거리=크기. “손동작 끄기”로 즉시 종료.
8. **저장/출력** — 브라우저 저장(자동+수동), JSON 저장/불러오기, 고해상도 PNG, PDF.
   결과물에는 UI·그리드 가이드가 포함되지 않습니다.

- `Delete` 삭제 · `[` 뒤로 · `]` 앞으로 · 방향키 한 칸 이동

## 폰트
프로젝트 전체에서 **2개 글꼴만** 사용합니다.
- **대형 타이포** — Apple Garamond (`local()`로 설치 여부 자동 감지, 없으면 Georgia/serif 폴백)
- **부 타이포 · UI** — Helvetica Neue / Helvetica / Arial 산세리프

## 구조
```
index.html
css/style.css
js/
  util.js         공통 헬퍼
  exif.js         무의존 EXIF(촬영시간·GPS) 리더
  state.js        단일 상태 + 실행취소/다시실행
  photos.js       사진 스토어·불러오기·인덱스·강조색 추출
  grid.js         그리드 메트릭·라인·아이템 렌더·스냅
  editor.js       선택·이동·리사이즈·크롭·드래그드롭·키보드
  typography.js   텍스트 아이템 렌더·프리셋(디스플레이/산세리프)
  inspector.js    선택 요소·프로젝트 메타 컨트롤
  memory.js       규칙 기반 Memory Grid 자동 배치
  commands.js     자연어 명령 프로토타입 (AI API로 교체 가능한 별도 모듈)
  export.js       localStorage·JSON·PNG·PDF (전부 무의존)
  gesture.js      옵션: @mediapipe/tasks-vision HandLandmarker (CDN 지연 로드)
  main.js         부트스트랩·와이어링
```

## 구현 상태 (우선순위 순)
1. 사진 불러오기 + 이미지 인덱스 — ✅
2. 그리드 캔버스 + 드래그&드롭 — ✅
3. 사진 이동·크기·크롭·확대·삭제·레이어·실행취소·교체 — ✅
4. 타이포그래피 — ✅
5. 저장 + PNG/PDF/JSON — ✅
6. 규칙 기반 Memory Grid — ✅
7. 자연어 명령 프로토타입 — ✅ (키워드 규칙; `commands.js`만 교체하면 AI 연결 가능)
8. 웹캠 손동작 (tasks-vision) — ✅ 옵트인 (실기기 웹캠 필요)
9. PDF — ✅ / 편집 과정 영상 출력 — 예정
